## 0. Canonical meaning of exact Owner confirmation (ratification)

**การยืนยันรายละเอียดแบบเจาะจงโดย Owner (exact Owner confirmation /
ratification)** ในชุดเอกสารนี้หมายถึงการตัดสินใจแบบ append-only หลังสร้าง
หลักฐานแล้ว โดย Owner ยืนยันว่า UUID ที่เลือกและค่า SHA-256 ที่ระบุทั้งหมดตรง
กับเจตนาทางธุรกิจเดิมซึ่งให้แก้ราคาเพียงหนึ่งรายการ และยอมรับ P-50C เป็น
**local review evidence only**.

คำสามคำต่อไปนี้ไม่ใช่สิ่งเดียวกัน:

- **business intent / ความประสงค์ทางธุรกิจ** เลือกเพียงรายการที่ต้องการแก้;
- **exact Owner confirmation (ratification) / การยืนยันรายละเอียดแบบเจาะจง**
  ยืนยันตัวตนและ hashes หลังสร้างหลักฐาน พร้อมรับผล P-50C เป็นหลักฐาน local;
- **execution authorization / การอนุมัติให้ดำเนินการ** อนุญาต action ที่ระบุ
  ชื่อและขอบเขตเป็นครั้งถัดไป ซึ่งต้องขอแยกต่างหาก.

Owner ตอบเป็นภาษาไทย อังกฤษ หรือผสมกันได้ และไม่จำเป็นต้องคัดลอกถ้อยคำแบบ
verbatim แต่ต้องระบุ bindings ทั้งหมดให้ตรงกันครบถ้วน. ข้อความสั้น เช่น
`ยืนยันตาม #54` เพียงอย่างเดียวยังไม่พอ เพราะเอกสาร working-tree นี้ยังไม่ถูก
commit/hash-bind เป็น authority ภายนอกข้อความตอบของ Owner.

การยืนยันนี้ไม่ใช่การตัดสินใจราคาใหม่ ไม่เปลี่ยน published/current
`2568.0.0` และไม่อนุญาต candidate application, commit, push, CI/Preview,
database, Production, network, P-13, P-14, P-14C, P-15, deploy หรือ
publication. คำว่า `RATIFY` คงอยู่เป็น command/request label เพื่อรักษา audit
trail และไม่มีความหมายกว้างกว่านิยามนี้.
